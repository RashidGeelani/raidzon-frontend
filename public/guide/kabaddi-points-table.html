How a kabaddi points table works

A points table (standings) ranks the teams in a league or group. Teams earn table points from results, and ties are broken by how many match points they scored and conceded. This is how RaidzOn calculates it, updated automatically after every completed match.

Table points for each result

ResultTable points
Win3
Draw1 each
Loss0

The columns

  • P: matches played
  • W / D / L: wins, draws, losses
  • PD: point difference, meaning total match points scored minus total conceded
  • Pts: table points

How teams are ranked

  1. Most table points.
  2. If level, better point difference.
  3. If still level, better scoring ratio (points scored compared with points conceded).

Teams that are still equal share the same rank.

Example

Valley Raiders beat City Warriors 34–29, then draw 25–25 with Lake Stars. They have 2 played, 1 win, 1 draw: 4 table points and a point difference of +5.

Tournament formats

  • League: every team in one table.
  • Groups + knockout: a table per group; the top teams qualify for the knockout rounds (and an optional third-place match).
  • Knockout: no table, just a bracket from the first round to the final.
